# App Legal Docs

This repository hosts **privacy policies** and **technical support** pages for our applications.

## Structure

```
├── <app-name>/
│   ├── privacy-policy.md
│   └── support.md
```

## Usage

Each app has its own directory. Add a new folder for each app and include the relevant documents.

## GitHub Pages

These documents can be served via [GitHub Pages](https://pages.github.com/) for easy public access.
